# 2048 Game

A browser-based implementation of the 2048 puzzle game, built with HTML, SCSS, and JavaScript. Combine tiles with equal numbers to reach the 2048 tile.

## Live Preview

[Play 2048](https://vadym-fe.github.io/game-2048/)

## Technologies Used

- HTML
- SCSS
- JavaScript
- Parcel

## Features

- Keyboard controls using the arrow keys
- Tile movement and merging
- Random tile generation after a successful move
- Score tracking
- Win and game-over messages
- Restart functionality

## How to Play

1. Click **Start** to begin.
2. Use the **arrow keys** to move the tiles.
3. Tiles with equal numbers merge when they meet.
4. Reach the **2048 tile** to win.
5. The game ends when no valid moves remain.
6. Click **Restart** to reset the game.

## Getting Started

### Requirements

Make sure Node.js and npm are installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Vadym-fe/game-2048.git
   ```

2. Navigate to the project folder:

   ```bash
   cd game-2048
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

Open the local URL displayed in the terminal.

## Available Commands

| Command          | Description                        |
| ---------------- | ---------------------------------- |
| `npm start`      | Start the local development server |
| `npm run lint`   | Check the code with linters        |
| `npm run build`  | Create a production build          |
| `npm run deploy` | Deploy the game to GitHub Pages    |
